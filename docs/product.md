# 宝宝照护记录 - 产品文档

## 产品定位

手机和平板优先的家庭共享照护 APP，专为婴幼儿家庭设计。支持多位家庭成员（爸爸、妈妈、爷爷、奶奶）实时协作记录宝宝的日常照护活动，包括喂奶、用药、推拿、排便等。

## 目标用户

- 主要用户：0-3 岁宝宝的父母
- 次要用户：爷爷奶奶等其他照护者
- 使用场景：家庭内多位成员共同照护，需要实时同步和追溯记录

## 核心功能

### 1. 照护记录

**功能描述**：记录宝宝的日常照护活动，支持多种照护类型。

**照护类型**：
- 母乳（左侧存储、右侧存储、瓶喂）
- 奶粉
- AD 滴剂
- VD 滴剂
- 益生菌
- 推拿
- 排便（大/中/小）

**核心指标**：
- 今日奶量（ml）
- 今日喂奶次数
- 今日排便次数
- 最近喂奶时间

### 2. 数据统计

**功能描述**：提供多维度的数据可视化和趋势分析。

**统计维度**：
- 七日趋势：最近 7 天的每日奶量
- 月度趋势：最近 30 天的每日奶量
- 总数据趋势：所有历史数据
- 月度每周统计：按周一至周日统计平均奶量

### 3. 成长记录

**功能描述**：每周记录宝宝的身高体重，追踪成长曲线。

**功能点**：
- 每周身高体重记录
- 首页未记录时提醒
- 档案展示最新数据和历史变化
- 显示每次记录的操作人和宝宝月龄

### 4. 家庭协作

**功能描述**：支持多位家庭成员独立登录，实时协作。

**家庭成员**：
- 爸爸：固定为超管
- 妈妈、爷爷、奶奶：可设置为管理员或普通用户

**权限管理**：
| 操作 | 超管 | 管理员 | 普通用户 |
|------|------|--------|----------|
| 查看记录 | ✅ | ✅ | ✅ |
| 新增/修改记录 | ✅ | ✅ | ✅ |
| 软删除记录 | ✅ | ✅ | ❌ |
| 恢复/彻底删除 | ✅ | ✅ | ❌ |
| 管理用药项目 | ✅ | ✅ | ❌ |
| 修改宝宝资料 | ✅ | ❌ | ❌ |
| 修改家庭权限 | ✅ | ❌ | ❌ |
| 配置 AI 模型 | ✅ | ❌ | ❌ |
| 配置消息推送 | ✅ | ❌ | ❌ |
| 数据备份/恢复 | ✅ | ❌ | ❌ |

**实时同步**：
- 家庭成员新增或修改记录后，其他设备实时更新
- 离线设备恢复联网后自动同步
- 使用持久化连接 + 低频轮询降级策略

### 5. 宝宝资料

**功能描述**：管理宝宝的基本信息。

**字段**：
- 姓名（必填）
- 性别
- 出生日期
- 昵称（可选，≤20 字符）
- 称谓（爸爸/妈妈/爷爷/奶奶，与登录身份联动）
- 头像（支持上传裁剪）

**头像裁剪**：
- 圆形裁剪框
- 支持拖拽平移
- 支持双指缩放
- 服务端自动压缩为 512×512 WebP 格式

### 6. AI 智能

**功能描述**：AI 辅助照护记录和日报生成。

**功能点**：
- AI 短语音转写（依赖浏览器 Web Speech API）
- DeepSeek 指令理解：将语音/文字转换为结构化的照护草稿
- 多条草稿确认后统一保存
- 未配置 AI 时明确使用浏览器语音，支持手动记录
- 每日凌晨自动生成前一天的「宝宝日报」

### 7. 消息推送

**功能描述**：通过 PushPlus 向微信推送重要提醒。

**推送类型**：

| 类型 | 说明 | 默认时间/阈值 |
|------|------|--------------|
| 早间日报 | 发送前一天的照护总结 | 每日 08:00 |
| 喂奶间隔（轻度） | 超过阈值时提醒 | 150 分钟 |
| 喂奶间隔（重点） | 严重超时提醒 | 180 分钟 |
| 用药与照护 | 定时提醒未完成项目 | 按项目设置 |

**功能特点**：
- 独立开关：每种推送类型可单独启用/禁用
- 测试按钮：可单独测试每种推送
- PushPlus 支持一对多消息，家庭成员可同时接收
- 推送模板包含喂奶摘要和用药计划

### 8. 数据管理

**功能描述**：保障数据安全和可追溯。

**功能点**：
- 每 6 小时自动保存服务器备份
- 支持手动备份、导出 JSON
- 支持事务恢复（恢复前自动保存当前数据）
- 管理员可软删除、查看已删除记录、恢复或彻底删除
- 同日同种用药重复保护

## 用户流程

### 首次使用流程

```
1. 爸爸首次打开 → 设置密码
2. 登录 → 进入首页
3. 添加宝宝资料（姓名、性别、出生日期）
4. 邀请家庭成员加入
5. 开始记录照护活动
```

### 日常使用流程

```
1. 打开 APP → 首页显示今日概览
2. 点击「+」按钮 → 选择照护类型
3. 填写记录详情 → 保存
4. 其他设备实时同步
5. 查看历史记录和数据统计
```

### 消息推送流程

```
1. 爸爸配置 PushPlus Token 和 Topic
2. 启用推送开关
3. 系统定时检查推送条件
4. 触发条件时发送推送
5. 微信收到消息提醒
6. 点击通知跳回 APP
```

## 页面结构

### 首页
- 宝宝问候语（时间段问候 + 昵称 + 称谓）
- 宝宝头像
- 今日核心指标（奶量、喂奶次数、排便次数）
- 今日计划（疫苗、用药提醒）
- 快捷操作（喂奶、用药、排便）

### 记录页
- 日历视图
- 时间线视图
- 新增记录按钮
- 搜索功能

### 档案页
- 宝宝基本资料
- 成长记录（身高体重历史）
- 疫苗档案

### 设置页
- 家庭权限管理
- AI 模型配置
- 消息推送配置
- 用药项目管理
- 数据备份与恢复

## 设计原则

1. **简洁实用**：优先解决用户任务，避免无意义的装饰
2. **实时同步**：多人协作时数据立即可见
3. **离线可用**：网络不稳定时仍可记录
4. **轻量高效**：移动端优先，加载速度快
5. **清晰反馈**：每个操作都有明确的状态反馈

## 数据隐私

- 语音原文只用于生成待确认草稿，不写入数据库
- AI 配置后短音频会发送给所选 AI 服务
- 应用无公开注册入口，仅供家庭内部使用
- 服务器自动备份与数据库位于同一存储
- 建议定期导出 JSON 备份到其他设备
