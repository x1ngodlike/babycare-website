# 宝宝照护记录 UI/UX 规范

## 设计原则

- 优先保证快速记录、清晰反馈和低认知负担。
- 复用同一类组件，不因页面不同重复设计按钮、菜单或弹窗。
- 插画只服务于品牌与空状态，不进入高信息密度列表、图表和设置项。
- 所有交互同时支持触摸、键盘与读屏语义，并尽量符合 WCAG 2.2 AA。

## 设计变量

- 间距：4、8、12、16、24、32px。
- 点击区域：不小于 44 × 44px；常规表单高度 48px。
- 圆角：控件 10px，卡片 16px，弹窗 20px，标签使用胶囊圆角。
- 页面标题：桌面 32px、移动端 28px；分区标题 20px；卡片标题 16px；正文 14px；标签 13px；辅助文字 12px。
- 阴影仅用于弹窗、操作菜单和悬浮反馈，不用于普通内容卡片。

## 颜色语义

- 页面背景 `--surface-page`，内容背景 `--surface-card`，弱背景 `--surface-subtle`。
- 主文字 `--ink`，辅助文字 `--text-secondary`，更弱文字仅用于非关键短标签。
- 绿色表示主操作、已完成与正常状态；橙色表示提醒；红色只表示危险操作或错误。
- 普通正文和辅助文字必须达到 4.5:1；图标与控件边界至少达到 3:1。

## 组件规则

- `SegmentedControl`：用于互斥视图，支持左右方向键，选中项只有一个。
- `ActionMenu`：所有“…”操作统一为 44px 触发区、128px 菜单和 13px 文案。
- `Dialog`：锁定焦点、Escape 关闭、关闭后恢复焦点；有未保存内容时必须确认。
- `ConfirmDialog`：标题说明结果，正文说明影响，危险确认按钮使用红色。
- `Switch`：必须有明确的可读名称；保存中禁用并提供反馈。
- `EmptyState`：标题说明当前状态，正文说明下一步，可选一个主要操作。
- `Toast`：成功与失败都必须可读；可撤销操作应提供明确的“撤销”。

## 响应式

- 320–520px：单列，卡片内边距 12–16px。
- 521–759px：单列或紧凑双列。
- 760–1079px：主要内容可双列，禁止产生无意义的大面积空白。
- 1080px 以上：页面最大宽度 1080px，不继续拉伸正文。

## 插画

- 暖米白、鼠尾草绿和柔和橙色，轻拟物、圆润、低饱和、透明背景、无文字。
- 空状态使用 1:1；登录主视觉使用 4:3。
- 同组素材保持相同光源、视角、描边与阴影强度。
- 首批场景：无记录、无搜索结果、无接种安排、登录家庭照护。

## 头像设计规范

### 尺寸规格
- 首页大头像：76×76px（桌面）、64×64px（移动端）
- 资料卡头像：56×56px（桌面）、48×48px（移动端）、40×40px（≤400px 屏幕）
- 头像裁剪输出：512×512px WebP 格式（服务端压缩）

### 裁剪交互
- 圆形裁剪框，支持拖拽平移和双指缩放
- 裁剪框占屏幕约 80% 宽度
- 实时预览裁剪效果
- 支持重置和取消操作

### 状态展示
- 默认状态：显示用户上传的头像
- 无头像时：显示小熊占位图（bear-bottle.png）
- 加载中：显示骨架屏或 loading 状态
- 上传失败：显示错误提示和重试按钮

### 存储路径
- 服务端存储：`{DATA_DIR}/uploads/avatars/avatar_{uuid}.webp`
- 静态访问：`/avatars/avatar_{uuid}.webp`
- 缓存策略：30 天浏览器缓存

## 消息推送设计规范

### 设置页面布局
- 卡片式布局，每个推送类型独立卡片
- 顶部状态汇总：显示当前推送总体状态（未配置/已开启/已关闭）
- 每个推送类型包含：开关、配置参数、测试按钮

### 推送类型卡片
1. **早间日报卡片**
   - 配置项：启用开关、发送时间（HH:MM）
   - 测试按钮：发送测试日报
   
2. **喂奶间隔卡片（轻度 🟡）**
   - 配置项：启用开关、阈值分钟数（≥30）
   - 测试按钮：发送轻度提醒
   
3. **喂奶间隔卡片（重点 🔴）**
   - 配置项：启用开关、阈值分钟数（> 轻度阈值，≥30）
   - 测试按钮：发送重点提醒
   
4. **用药与照护卡片**
   - 配置项：启用开关
   - 测试按钮：发送照护提醒

### 推送消息模板
- 统一使用 HTML 卡片格式
- 字体：系统字体栈（-apple-system, BlinkMacSystemFont, PingFang SC）
- 字号：14px 正文、17px 标题、12px 辅助文字
- 配色：
  - 早报：绿色系（#2b6b3e）
  - 轻度提醒：黄色系（#d98e0b）
  - 重点提醒：红色系（#c44032）
- 包含：标题栏、喂奶摘要、用药计划（含状态标签）、分隔线

### 状态标签样式
- 已完成：绿色背景（#e8f2ec）+ 深绿文字（#2b6b3e）
- 待记录：黄色背景（#fdf3de）+ 橙色文字（#a36b00）
- 按需使用：蓝色背景（#e6eff5）+ 蓝色文字（#3a6f8c）

### 测试按钮规范
- 按钮文案：「发送测试日报」、「发送轻度测试」、「发送重点测试」、「发送照护测试」
- 喂奶间隔测试按钮保留 🟡/🔴 前缀以示区分
- 其他测试按钮不含 emoji
- 测试结果通过 Toast 反馈：成功/失败

## 首页问候语设计

### 时间段问候
- 06:00-11:59：早安
- 12:00-17:59：午安
- 18:00-22:59：晚上好
- 23:00-05:59：夜深了

### 展示格式
```
{问候语}，{昵称}{称谓}～
```
示例：「午安，小糯米爸爸～」

### 宝宝年龄展示
- 格式：{大名} · {阶段标签} · {月龄}
- 阶段标签：
  - 0-29 天：新生儿
  - 30-99 天：满月宝宝
  - 100-179 天：百天宝宝
  - 180 天 - 1 岁：小月龄
  - ≥1 岁：不显示阶段标签

## 宝宝资料字段

### 基本信息
- 昵称：≤20 字符，显示在首页问候语
- 称谓：自定义（爸爸/妈妈/爷爷/奶奶），与当前登录身份联动
- 头像：支持上传裁剪，WebP 格式存储

### 权限说明
- 宝宝资料仅超管（爸爸）可编辑
- 其他家庭成员仅可查看
- 修改操作记录操作人和时间
